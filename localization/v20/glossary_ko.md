# SpendZero 2.0 — Korean (ko) glossary

Register: friendly 해요체 for sentences ("~해요", "~해 보세요"), short nouns for labels/buttons/chips
("도장 찍기", "구독 관리"). User's name always takes 님 ("%@님"). Siri phrases use the spoken
"~해 줘" form people actually say to Siri. Avoid 이/가, 을/를, 은/는 directly after %@ when %@ is an
amount or a free-text item (pronunciation unknown); use invariant particles (의, 에, 까지, 만큼, 님) or
restructure. Month names (%@ = "10월") always end in a consonant, so 이/은 is safe there.
